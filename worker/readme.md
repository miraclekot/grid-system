# worker

Worker узел распределенной вычислительной системы Grid System. Выполняет подзадачи, полученные от master-узла: находит все возможные размещения слов в матрице и возвращает результаты.

## Структура

```
worker/
├── worker/
│   ├── __init__.py
│   └── main.py          # Точка входа и класс Worker
└── setup.py             # Установочный файл
```

## Компоненты

### main.py - Worker

Класс `Worker` реализует всю функциональность рабочего узла:

| Метод | Описание |
|-------|----------|
| `register()` | Регистрация в master-узле |
| `start_heartbeat()` | Запуск отправки heartbeat |
| `handle_task(request)` | Обработка подзадачи |
| `find_placements(matrix, word)` | Поиск всех размещений слова |
| `start()` | Запуск HTTP сервера |
| `stop()` | Остановка worker |

## Алгоритм поиска размещений

Для каждого слова:
1. Найти все позиции первой буквы слова в матрице
2. Для каждой позиции проверить все 8 направлений
3. Проверить, помещается ли слово целиком в выбранном направлении
4. Сохранить координаты всех клеток размещения

**Направления:**
- Горизонтальные: → (0,1), ← (0,-1)
- Вертикальные: ↓ (1,0), ↑ (-1,0)
- Диагональные: ↘ (1,1), ↙ (1,-1), ↗ (-1,1), ↖ (-1,-1)

## API Endpoints

| Endpoint | Method | Description | Request Body | Response |
|----------|--------|-------------|--------------|----------|
| `/task` | POST | Получение подзадачи | `{"id": int, "words": [str], "matrix": [[str]]}` | `{"placements": [...]}` |
| `/status` | GET | Статус воркера | - | `{"worker_id": int, "busy": bool, "current_task": int}` |

### Формат ответа `/task`

```json
{
  "placements": [
    {
      "word": "hello",
      "row": 0,
      "col": 0,
      "dr": 0,
      "dc": 1,
      "cells": [[0,0], [0,1], [0,2], [0,3], [0,4]]
    }
  ]
}
```

## Heartbeat

Worker отправляет heartbeat каждые 5 секунд для подтверждения активности:

```json
{
  "worker_id": 0,
  "status": "available",  // или "busy"
  "current_task": null    // или ID текущей задачи
}
```

## Логирование

Worker выводит логи в консоль:

```
2026-03-28 10:20:15 - grid_system.worker - INFO - Registered with master, worker_id = 0
2026-03-28 10:20:16 - grid_system.worker - INFO - Worker listening on 127.0.0.1:5000
2026-03-28 10:20:20 - grid_system.worker - INFO - Processing task 0 with 12 words
2026-03-28 10:20:21 - grid_system.worker - INFO - Task 0 completed in 0.45s, found 234 placements
```

**Уровни логирования:**
- `INFO` - Основные события (регистрация, получение задачи, завершение)
- `DEBUG` - Детальная информация (количество размещений для каждого слова)
- `WARNING` - Предупреждения (сбой heartbeat)
- `ERROR` - Ошибки (сбой регистрации, ошибки обработки)

## Запуск

```bash
worker <master_url> [--host HOST] [--port PORT]
```

**Параметры:**

| Параметр | Описание | Обязательный | По умолчанию |
|----------|----------|--------------|--------------|
| `master_url` | URL master-узла (например, http://127.0.0.1:8080) | Да | - |
| `--host` | Адрес для прослушивания | Нет | 127.0.0.1 |
| `--port` | Порт для прослушивания | Нет | 5000 |

## Пример запуска

```bash
# Запуск worker с подключением к master на localhost
worker http://127.0.0.1:8080

# Запуск worker на другом порту
worker http://192.168.1.100:8080 --port 5001

# Запуск worker с прослушиванием всех интерфейсов
worker http://127.0.0.1:8080 --host 0.0.0.0 --port 5000
```

## Завершение работы

Worker корректно обрабатывает прерывание `Ctrl+C`:
- Останавливает отправку heartbeat
- Закрывает HTTP сессию
- Выводит сообщение о завершении

```bash
^C
Shutting down...
2026-03-28 10:25:30 - grid_system.worker - INFO - Stopping worker...
Worker stopped.
```

## Тестирование

Для тестирования worker без master-узла можно использовать curl:

```bash
# Проверка статуса
curl http://127.0.0.1:5000/status

# Отправка тестовой задачи
curl -X POST http://127.0.0.1:5000/task \
  -H "Content-Type: application/json" \
  -d '{
    "id": 1,
    "words": ["ab", "cd"],
    "matrix": [["a","b","c"],["d","e","f"],["g","h","i"]]
  }'
```

## Производительность

- Worker обрабатывает слова последовательно
- Поиск размещений выполняется за O(H × W × L), где:
  - H - высота матрицы
  - W - ширина матрицы
  - L - длина слова
- Для оптимизации используется индексация по первой букве
