# Grid System - Распределенная система размещения слов в матрице

## Описание проекта

Распределенная вычислительная система для решения задачи оптимального размещения слов из словаря в матрице букв. Система состоит из master-узла и worker-узлов, которые взаимодействуют через HTTP API. Master распределяет словарь на подзадачи, worker-ы вычисляют все возможные размещения слов и возвращают результаты. Master собирает результаты и находит оптимальную комбинацию размещений, минимизирующую количество незадействованных букв.

## Возможности

- **Распределенные вычисления**: Master распределяет словарь на подзадачи с учетом сложности
- **Динамические воркеры**: Воркеры могут подключаться и отключаться во время выполнения
- **Отказоустойчивость**: Heartbeat-мониторинг, автоматическое перераспределение задач
- **Персистентное хранение**: Сохранение состояния вычислений между запусками
- **Удобный консольный интерфейс**: Интерактивное меню с просмотром статуса, логов и подзадач
- **Поддержка всех направлений**: Горизонтальное, вертикальное, диагональное, чтение в обоих направлениях

## Запуск системы

### Запуск master-node

```bash
master-node
```

При запуске потребуется указать:
- Путь к файлу матрицы
- Путь к файлу словаря
- Коэффициент сложности

### Запуск worker

```bash
worker http://127.0.0.1:8080 --port 5000
```

Параметры:
- `master_url`: URL master-узла (обязательный)
- `--host`: Адрес для прослушивания (по умолчанию: 127.0.0.1)
- `--port`: Порт для прослушивания (по умолчанию: 5000)


## Алгоритм работы

1. **Генерация подзадач**
   - Для каждого слова вычисляется количество возможных размещений
   - Слова группируются в подзадачи с учетом коэффициента сложности
   - Сложные слова (количество размещений > коэффициента) получают отдельную подзадачу

2. **Распределение задач**
   - Master поддерживает пул активных воркеров через heartbeat
   - Задачи распределяются по принципу "first available worker"
   - При отказе воркера задача автоматически перераспределяется

3. **Вычисление размещений**
   - Worker для каждого слова находит все возможные позиции в матрице
   - Учитываются все 8 направлений
   - Результат возвращается мастеру в виде списка размещений

4. **Оптимизация покрытия**
   - После получения всех результатов применяется жадный алгоритм покрытия
   - Выбираются размещения, покрывающие максимальное количество клеток
   - Результат - минимальное количество незадействованных букв

## Конфигурация

Параметры конфигурации (можно изменить через меню настроек):

| Параметр | Описание | Значение по умолчанию |
|----------|----------|---------------------|

| `master_port` | Порт master HTTP сервера | 8080 |

## Особенности реализации

- **Асинхронность**: Использование asyncio и aiohttp для неблокирующего ввода-вывода
- **Потокобезопасность**: Асинхронные блокировки для доступа к общим данным
- **Heartbeat-механизм**: Воркеры отправляют heartbeat каждые 5 секунд, мастер отслеживает их состояние
- **Персистентность**: Сохранение выполненных подзадач в текстовый файл для восстановления после перезапуска
- **Жадное покрытие**: Эффективный алгоритм выбора оптимального набора размещений

## Ограничения

- Матрица должна быть полностью заполнена буквами (без пробелов)
- Слова в словаре должны содержать только латинские буквы
